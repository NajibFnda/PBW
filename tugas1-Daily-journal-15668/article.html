Hari Pertama Perkuliahan Semester Baru di Kampus UDINUS

Pekan perkuliahan resmi dimulai pagi ini di Universitas Dian Nuswantoro. Suasana Gedung H terasa ramai oleh mahasiswa Teknik Informatika yang kembali bertemu setelah libur semester. Sesi pagi diisi dengan pengenalan kontrak kuliah, rencana pembelajaran semester, serta pembagian proyek kecil yang akan dikerjakan secara bertahap hingga ujian tengah semester.

Sepulang dari kelas, saya langsung menyusun ulang jadwal belajar mingguan dan merapikan folder catatan mata kuliah di laptop. Target saya di semester ini sederhana: lebih konsisten mencatat poin penting setiap selesai kelas agar tidak menumpuk menjelang ujian.

#02 2. Selasa, 12 September 2023 Pemrograman Web 2 mnt baca

Mengenal Struktur Semantik HTML5 pada Pemrograman Berbasis Web

Hari ini mata kuliah Pemrograman Berbasis Web membahas fondasi pembuatan halaman web modern menggunakan HTML5. Kami mempraktikkan langsung penggunaan elemen semantik seperti <header>, <nav>, <main>, <article>, dan <footer> dibandingkan hanya mengandalkan tag <div> di seluruh dokumen.

Ternyata penulisan struktur HTML yang jelas memberikan banyak manfaat sekaligus: kode lebih mudah dirawat, screen reader dapat menavigasi halaman dengan baik, dan tata letak CSS nantinya jauh lebih terorganisasi.

Lab Komputer · Pemrograman Berbasis Web
#03 3. Rabu, 13 September 2023 Kampus 2 mnt baca

Diskusi Kelompok & Merancang Konsep Daily Journal Online

Selepas kelas siang, saya bersama teman-teman sekelas berdiskusi santai di selasar kampus mengenai konsep tugas pembuatan web Daily Journal. Kami memetakan tiga halaman utama yang saling terhubung: Home sebagai ringkasan, Article untuk daftar tulisan harian, dan Gallery untuk menampilkan dokumentasi foto serta video kampus.

Dari diskusi tersebut saya menyadari bahwa desain yang nyaman dibaca tidak harus rumit. Hierarki tipografi yang tepat, jarak antar elemen yang lega, dan konsistensi navigasi di setiap halaman sudah sangat menentukan kenyamanan pengunjung.

Selasar Kampus · UDINUS Semarang
#04 4. Kamis, 14 September 2023 Perkuliahan 2 mnt baca

Memperdalam Logika Algoritma dan Latihan Pemecahan Masalah

Kamis diisi dengan latihan soal algoritma yang menantang. Fokus utama materi hari ini adalah menganalisis kompleksitas waktu sederhana serta membandingkan efektivitas beberapa pendekatan perulangan dan struktur data dasar.

Mencoba menuliskan alur pemikiran di kertas terlebih dahulu sebelum menyentuh editor kode benar-benar mempercepat proses debugging. Kesalahan kecil seperti kondisi batas (edge case) jadi jauh lebih cepat terdeteksi.

Ruang Kuliah · Teknik Informatika
#05 5. Jumat, 15 September 2023 Pemrograman Web 2 mnt baca

Menata Layout Web Responsif Menggunakan CSS Flexbox & Grid

Sore ini saya meluangkan waktu khusus untuk bereksperimen dengan CSS Flexbox dan CSS Grid agar tampilan halaman web bisa menyesuaikan diri dengan rapi baik di layar laptop maupun ponsel. Salah satu bagian menariknya adalah mengatur proporsi kolom artikel dan galeri agar tetap seimbang.

Selain itu, memisahkan gaya ke dalam satu file style.css eksternal membuat pembaruan warna, tipografi, dan spasi di seluruh halaman jauh lebih cepat serta bebas duplikasi kode.
